# Security, privacy, and glossary

The app and these Docs live inside the authenticated area. Backend operations derive the user from the session; never treat a shared link or screenshot as authorization for another person.

## Good practices

- Never share Telegram link codes, screenshots containing IBANs, or sensitive spending details.
- Complete bank consent only on your bank's page and verify the domain before signing in.
- When consent expires, use **Renew bank consent** in **Settings → Bank Connections**; do not enter bank credentials inside Tracky.
- Before approving an Analyst proposal, review its amount, category, account, and recurrence.
- End the session if a device is no longer under your control.

## Sessions and technical diagnostics

Tracky asks browsers and shared caches not to store dynamically generated pages or server-function responses. Error screens in production omit technical stack traces. Always sign out on a shared device; these controls do not erase a screenshot or an already opened page.

If technical Analyst tracing is enabled, prompt, tool-input and answer bodies are excluded from those traces. Technical metadata and user/thread identifiers can still be included. This does not change the messages stored in your Analyst history or the data sent to AI providers to answer your request. Optional usage analytics follows your separate consent choice in Settings.

## Essential glossary

| Term                | Meaning in Tracky                                                                    |
| ------------------- | ------------------------------------------------------------------------------------ |
| Booked balance      | Balance published by the bank for booked transactions.                              |
| Preferred balance   | Value Tracky selects in the newest snapshot: available, then booked, then expected. |
| Tracky availability | Preferred balance plus a linked overdraft; for CARD it is not cash liquidity.       |
| `DBIT`              | Money leaving an account; it decreases the balance.                                  |
| `CRDT`              | Money entering an account; it increases the balance.                                 |
| Minor unit          | Integer money representation, such as cents for EUR, based on the currency exponent. |
| `CACC`              | Current account.                                                                     |
| `CARD`              | Card ledger; a liability that is not added to cash.                                  |
| Credit facility     | Contract defining limit, usage, and availability. It is not a cash account.          |
| Settlement account  | Current account charged for the card statement.                                      |
| Cycle / statement   | A month's closed card amount expected for payment.                                   |
| Transfer            | Opposite legs between your own accounts; neither new spending nor income.            |
| Internal            | An adjustment or internal payment excluded from spending totals.                     |
| Money box           | A virtual allocation toward a target; it does not move bank funds.                   |
| First negative date | First due item that takes projected cash below zero in the cycle.                    |

<Callout title="No automatic conversion">
  EUR, USD, and other currencies keep separate totals. Tracky does not invent an exchange rate to create a single
  figure.
</Callout>
